# 3D-Cooperative Minesweeper

## Идея проекта
3д кооперативный Сапёр с двумя режимами:
- **Min-Max**: ошибка одного игрока приводит к поражению всей команды.
- **Casual**: при ошибке выбывает только ошибившийся игрок, остальные могут завершить игру.

## План фич

### Итерация 1
- Базовое 3д поле; реакция карты на события (К)
- Модель и перемещение игрока, камера игрока и генерация событий (К) 
- Реализация всех правил Сапёра: генерация мин, подсчёт цифр, рекурсивное открытие пустых клеток. (Б)
- Обработка входящих событий: определение мины, открытие клетки, проверка победы/поражения. (Б)

### Итерация 2
- Сетевая синхронизация: создание комнаты, подключение второго игрока, обмен событиями; (К)
- Улучшение графики (модели, текстуры, анимации). (К)
- Реализация GUI с возможностью выбора игрового режима (К)
- Обработка игровых режимов со стороны логики сапера (Б)
- Тесты на логику (pytest). (Б)
- Фича от ассистента. (К/Б)

## Используемые библиотеки
- **Panda3D** — 3D-движок.
- **python-enet** — сетевая синхронизация.
- **pytest** — тестирование.
- **cProfile** + **snakeviz** — профилирование.


### Запуск
- У вас должны быть установлены Git и Python
- Далее откройте PowerShell
- Клонируйте репозиторий (ссылка выше)
- Выполните из корня репозитория (версия для powershell):
```bash
cd minesweeper
python -m venv venv 
venv\Scripts\python -m pip install -r requirements.txt
venv\Scripts\python -m main.main
```
